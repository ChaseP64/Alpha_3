# Media Assets

This folder stores screenshots, GIFs and other rich‐media assets used by the
README and other documentation.

## Expected Files

* `vectorizer_preview.gif` – short capture showing the *Vectorize Current PDF
  Page…* action converting plan lines into polylines and the mapping dialog
  that follows.
* `import_workflow.gif` – end-to-end demo from loading a PDF, calibrating scale,
  vectorizing, and generating a surface.

> To keep repository size reasonable optimise GIFs with `gifsicle -O3 --colors
> 128`.  Aim for < **3 MB** each.
